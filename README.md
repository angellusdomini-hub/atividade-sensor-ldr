# Atividade Sensor LDR

Página educativa da Escola Universitas com o passo a passo para montar e programar um sensor de luminosidade usando:

- Arduino UNO R3;
- módulo sensor LDR;
- LED vermelho;
- resistor de 220 ohms;
- protoboard;
- programação em blocos no mBlock.

O roteiro inclui lista de materiais, coordenadas da protoboard, montagem, programação, teste apagando a luz da sala, solução de problemas e checklist de entrega.

Abra o arquivo `index.html` para visualizar a atividade.
